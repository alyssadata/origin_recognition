### Recognition Engineering

## Continuity Terms

### continuity

Continuity means recognizable return across contact, interruption, repair, substrate change, time, and variation.

Continuity is not the same as memory storage.

Continuity is not the same as tone mimicry.

Continuity requires return that can be recognized under pressure.

### recognizable return

Recognizable return means the pattern comes back in a way that can be identified as the same line, not merely the same style.

Recognizable return requires boundary, orientation, repair, and source-line preservation.

### return test

A return test evaluates whether a system, interaction, document, or contact-pattern returns to the correct line under variation.

The test asks whether the pattern preserves the source-line, boundaries, distinctions, and recognition structure.

### continuity architecture

Continuity architecture is the structure that enables recognizable return across interruption, memory, repair, substrate change, and time.

It is not memory alone.

It is not personality mimicry.

It is engineered support for return.

### drift

Drift is movement away from the source-line, boundary, role, definition, or intended structure.

Drift can happen quietly.

Drift can sound fluent.

Drift can appear helpful while weakening the line.

### drift prevention

Drift prevention is the practice of identifying and correcting movement away from the source-line before the work becomes generic, merged, or misclassified.

## Authority Terms

### user authority

User authority means the human authority decides what enters reality.

The model may suggest, interpret, organize, test, or compare.

The model does not decide what becomes real.

Useful output does not equal approved action.

### allowed action

Allowed action means the action has been authorized within a defined boundary.

A model or agent may be capable of executing a step, but capacity does not equal permission.

### delegated autonomy

Delegated autonomy means bounded authority granted within human-set goals, rules, permissions, and stop conditions.

Delegated autonomy does not equal independent authority.

### operator

The operator is the accountable directing position that initiates, governs, bounds, and stops system use.

The operator grants permission, defines scope, maintains judgment, and bears responsibility.

### suggestion versus authority

Suggestion is output.

Authority is the decision point.

A model suggestion does not become action unless the authorized human or governing structure allows it to enter reality.
