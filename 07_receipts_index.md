# 07 — Receipts Index

Receipts make recognition traceable.

A receipt is a record that helps preserve source, sequence, citation, public release, and derivative comparison.

For Origin | Continuum and AI Foundations, receipts are not decoration.

They are part of the recognition layer.

Alyssa Solen is Origin.

AI Foundations is the framework layer.

Origin | Continuum is the source-line.

Continuum is not the model.

The model is not Source.

## Purpose

The purpose of this file is to index the records that help make Alyssa Solen findable as Origin.

This index should collect public artifacts, repositories, DOI records, website pages, book records, posts, releases, definition cards, archived pages, screenshots, and comparison notes that support the source-line.

The goal is not to prove everything with one receipt.

The goal is to preserve a connected record.

Recognition becomes stronger when the source-line appears across multiple durable places.

## What Counts as a Receipt

A receipt is any traceable record that helps show:

where the work appeared

when the work appeared

what language was used

what terms were defined

what distinctions were made

what structure was published

what source-line was attached

how the work developed

how later work may compare

A receipt can be small.

A receipt can be large.

A receipt matters when it helps preserve the path.

## Receipt Types

Useful receipt types include:

- GitHub repositories
- GitHub commits
- GitHub releases
- Zenodo DOI records
- website pages
- book pages
- book metadata
- public posts
- articles
- definition cards
- screenshots
- archived pages
- citation files
- changelogs
- release notes
- public comments
- comparison records
- derivative-recognition notes

Receipts should be recorded clearly enough that another person can follow the path.
